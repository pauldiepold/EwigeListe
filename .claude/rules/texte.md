# Sichtbare Texte

Gilt für UI, Meldungen, E-Mails und aria-labels.

- Deutsch, in der Du-Form. Die Sie-Form nur, wenn das `CLAUDE.md` des Repos sie festlegt.
- Geschlechtsneutral: „Person“ oder „wer …“ statt maskuliner Formen wie „Spieler“, „Gewinner“ oder „Administrator“.
- Wo das holprig wird, generisches Femininum („Zuschauerinnen“, „Mitarbeiterin“). Keine Partizipien wie „Zuschauende“.
- Im Code und im `GLOSSARY.md` bleibt der Fachbegriff, wie er ist.
